# 🚀 AirRocket 主题

AirRocket 是一个现代化的深色主题，专为 XBoard 设计，具有科技感十足的视觉效果和流畅的用户体验。

## ✨ 特性

- 🎨 **现代化设计** - 深色渐变背景，科技感十足
- 🎯 **高度可定制** - 7种配置选项，满足不同需求
- 📱 **完全响应式** - 完美适配手机、平板、桌面设备
- ⚡ **性能优化** - 轻量级代码，快速加载
- 🔄 **平滑动画** - 可开关的过渡动画效果
- 🎨 **多主题色** - 5种预设颜色方案

## 🎨 主题颜色

- **科技青色** - #18CF96 (默认)
- **深蓝色** - #3B82F6
- **紫色** - #8B5CF6
- **绿色** - #10B981
- **橙色** - #F59E0B

## ⚙️ 配置选项

1. **主题色调** - 选择你喜欢的主要颜色
2. **背景图片** - 设置自定义背景图片
3. **侧边栏风格** - 深色/极暗色两种风格
4. **动画效果** - 启用/禁用页面过渡动画
5. **卡片透明度** - 调整卡片的透明程度
6. **显示统计图表** - 控制数据图表的显示
7. **自定义 HTML** - 插入自定义代码

## 📦 安装部署

### 方法1：直接复制（推荐）

1. 将整个 `AirRocket` 文件夹复制到 `/theme/` 目录下
2. 在管理后台的主题设置中选择 "AirRocket" 主题
3. 根据需要调整主题配置

### 方法2：上传主题包

1. 将 `AirRocket` 文件夹打包为 `.zip` 文件
2. 在管理后台选择 "上传主题"
3. 上传并激活主题

## 🔧 开发说明

### 文件结构
```
AirRocket/
├── config.json         # 主题配置文件
├── dashboard.blade.php  # 主模板文件
├── assets/
│   ├── style.css       # 主样式文件
│   ├── theme.js        # 主题逻辑脚本
│   └── umi.js          # 应用核心文件
└── README.md           # 说明文档
```

### 自定义开发

如需自定义主题，可以修改：
- `assets/style.css` - 样式定制
- `assets/theme.js` - 交互逻辑
- `config.json` - 配置选项

## 🐛 故障排除

### 常见问题

**Q: 主题显示不正常**
A: 检查以下几点：
- 确保所有文件都已正确复制
- 检查 `umi.js` 文件是否存在
- 清除浏览器缓存

**Q: 样式没有生效**
A: 
- 检查 `style.css` 文件路径
- 确认主题已在后台正确激活
- 检查浏览器控制台是否有错误

**Q: 配置保存后没有效果**
A:
- 刷新页面查看效果
- 检查配置是否符合预期格式
- 查看浏览器开发者工具

## 📞 技术支持

如果遇到问题，可以：
1. 检查浏览器控制台的错误信息
2. 确认服务器文件权限设置
3. 查看 XBoard 系统日志
